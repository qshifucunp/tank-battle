# 坦克大战 · Battle City

一个用纯 HTML + Canvas + JavaScript 实现的经典《坦克大战》网页游戏，单个 `index.html` 文件即可运行，无需任何依赖或构建步骤。

## 特性

- 🎮 经典玩法：守住底部基地，消灭所有敌军坦克
- 🧱 三种地形：可破坏的砖墙、不可破坏的钢墙、坦克无法通过但子弹可穿过的水面
- 🚀 三种敌人：普通、快速、装甲（需要多次命中）
- 🎁 随机道具：护盾（S）、加命（♥）、炸弹（✱，消灭全场敌人）
- 🔊 音效：使用 Web Audio API 实时合成，可按 M 键静音
- 🏆 最高分保存在浏览器本地（localStorage）
- 📈 4 个关卡，难度递增

## 如何运行

直接用浏览器打开 `index.html` 即可，或通过任意静态服务器托管。

也可以在线游玩（如果启用了 GitHub Pages）：
`https://<你的用户名>.github.io/<仓库名>/`

## 操作

| 按键 | 功能 |
| --- | --- |
| 方向键 / WASD | 移动 |
| 空格 / J | 射击（可长按连发） |
| P / Esc | 暂停 |
| M | 静音开关 |
| Enter | 开始 / 重新开始 |

## 技术说明

- 13 × 13 网格地图，每个格子 32px
- 像素风渲染（`image-rendering: pixelated`）
- 基于 `requestAnimationFrame` 的 60fps 游戏循环
- 碰撞检测基于网格的轴对齐矩形（AABB）
